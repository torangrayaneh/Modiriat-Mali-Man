# مدیریت مالی من — پروژه اندروید

اپلیکیشن فارسی ثبت واریزی و هزینه با ذخیره محلی SQLite و پیشنهاد عنوان/آخرین مبلغ هزینه‌های قبلی.

## ساخت APK
1. این پوشه را در Android Studio باز کنید.
2. در صورت درخواست، Gradle Sync را انجام دهید (این پروژه به Android Gradle Plugin 8.7.3 و Android SDK 35 نیاز دارد).
3. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.
4. فایل APK معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکات نسخه اولیه
- اطلاعات داخل دیتابیس محلی گوشی ذخیره می‌شوند و بدون اینترنت قابل ثبت هستند.
- واحد پول تومان است.
- تاریخ‌ها در نسخه اولیه با قالب میلادی `YYYY-MM-DD` ثبت می‌شوند.
- پیشنهاد هزینه با عنوان‌های قبلی و آخرین مبلغ ثبت‌شده کار می‌کند.
- گزارش ماهانه بر اساس ماه میلادی است. تبدیل کامل تاریخ شمسی، ویرایش/حذف تراکنش‌ها، خروجی اکسل و پشتیبان‌گیری برای نسخه بعدی پیشنهاد می‌شوند.
